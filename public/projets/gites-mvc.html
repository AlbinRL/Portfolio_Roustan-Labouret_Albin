SN1 · Nov. – Déc. 2024

Gestion BDD et MVC sur des gîtes

PHP MySQL MVC

Contexte

Application web de gestion de gîtes ruraux : hébergements, disponibilités et réservations. Le projet introduit une architecture MVC et une base de données relationnelle.

Objectifs

  • Modéliser les entités (gîtes, clients, réservations) en SQL.
  • Séparer modèle, vues et contrôleurs en PHP.
  • Proposer un CRUD fonctionnel pour l'administration.

Réalisations

Schéma relationnel, scripts de création de tables, classes modèle avec PDO, contrôleurs pour lister/ajouter/modifier les gîtes, vues PHP intégrant les données. Tests manuels des parcours principaux.

Compétences mobilisées (E4)
