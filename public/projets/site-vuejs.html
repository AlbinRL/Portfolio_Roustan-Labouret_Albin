Site Vue.js

Application Vue 3 : composants, SPA, formulaires validés et appels API côté front-end

Vue 3 Vite JavaScript HTML CSS

Contexte

Projet web réalisé avec Vue 3 en 2ème année pour consolider les bases du framework : application front interactive, orientée composants, navigation en SPA et manipulations de données via API.

L'objectif était de mettre en pratique une architecture moderne (composants réutilisables, état local avec ref et reactive) tout en travaillant la présence en ligne par une interface dynamique et structurée.

Objectifs

  • Construire une navigation simple entre plusieurs sections de l'application.
  • Créer un formulaire avec validation côté client et messages d'état.
  • Consommer des APIs externes et afficher les réponses de manière lisible.
  • Mettre en place un composant bonus de type accordéon.
  • Structurer proprement le code en composants réutilisables.

Réalisations

Navigation & pages

SPA avec pages internes (accueil, contact, API, bonus) et routage entre les vues sans rechargement complet.

Formulaire de contact

Formulaire avec règles de validation, retours utilisateur (succès / erreur) et gestion des états du composant.

Testeur d'API & intégrations

Interface configurable (URL, méthode HTTP, body JSON) avec fetch vers des APIs externes (JSONPlaceholder, Chuck Norris API) et affichage formaté des réponses JSON.

Composant accordéon (bonus)

Accordéon affichant un tableau d'utilisateurs et une blague récupérée via API, pour illustrer la réutilisation de composants et le traitement de flux distants.

Technologies & outils

Vue 3 — framework, composants et réactivité (ref, reactive)
Vite / Vue CLI — outillage, scripts npm (dev, build, preview)
HTML, CSS, JavaScript — intégration et styles des vues
API REST — JSONPlaceholder, Chuck Norris API
