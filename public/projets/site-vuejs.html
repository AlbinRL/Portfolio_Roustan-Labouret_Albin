SN2 · Nov. – Déc. 2025

Site en Vue.js

Vue.js JavaScript HTML CSS

Contexte

Projet front-end avec Vue.js pour construire une interface dynamique sans rechargement complet des pages : composants réutilisables, données réactives et routing côté client.

Objectifs

  • Structurer l'application en composants Vue.
  • Gérer l'état et les interactions utilisateur.
  • Améliorer la présence web via une SPA moderne (D3).

Réalisations

Initialisation du projet (Vite ou CLI Vue), pages avec Vue Router, formulaires et listes dynamiques, consommation d'une API REST fictive ou JSON local, styles CSS scoped et build de production. Bilan sur les bonnes pratiques de découpage des composants.

Compétences mobilisées (E4)

D3, T4, O6
