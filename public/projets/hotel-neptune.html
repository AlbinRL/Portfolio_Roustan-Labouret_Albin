SN1 · Jan. – Mars 2025

Projet solution web — Hôtel Neptune

HTML PHP MySQL JavaScript

Contexte

Projet fil rouge « solution web » pour un hôtel fictif Neptune : site de présentation, gestion des chambres et parcours de réservation en ligne, avec travail en équipe sur plusieurs sprints.

Objectifs

  • Couvrir l'ensemble du cycle projet (expression de besoin, conception, réalisation, recette).
  • Développer front et back avec persistance des données.
  • Mettre en production un service utilisable (M5).

Réalisations

Spécifications fonctionnelles, maquettes, modèle de données chambres/réservations/clients, développement PHP avec authentification simple, pages de consultation et formulaire de réservation, tests et documentation utilisateur. Présentation finale devant le formateur.

Compétences mobilisées (E4)

G1, R2, D3, T4, M5, O6
