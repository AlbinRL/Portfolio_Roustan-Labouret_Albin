Application mobile avec Flutter

Flutter Dart Android Studio

Contexte

Découverte du développement mobile cross-platform avec Flutter et Android Studio : interface Material, navigation entre écrans et logique métier en Dart.

Objectifs

  • Créer une application fonctionnelle sur émulateur ou appareil.
  • Maîtriser widgets, état et routing de base.
  • Mettre à disposition un service mobile testable (M5).

Réalisations

Projet Flutter avec plusieurs écrans (liste, détail, formulaire), gestion d'état simple (setState ou provider selon consigne), appels éventuels à une API mock, build APK de démonstration et présentation des choux UX retenus.

Compétences mobilisées (E4)

G1, T4, M5, O6
